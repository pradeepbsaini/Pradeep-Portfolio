# Pradeep Saini — Digital Marketing Portfolio

A responsive, dark-theme personal portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files

- `index.html` — page structure, content, SEO metadata and Person structured data
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation, footer year and copy-email interaction
- `assets/pradeep-saini-portrait.png` — transparent monochrome portrait used in the hero

## Publish with GitHub Pages (beginner steps)

1. Sign in at https://github.com/
2. Click **New repository**.
3. For the simplest personal website URL, name the repository exactly `YOUR-USERNAME.github.io`, replacing `YOUR-USERNAME` with your GitHub username.
4. Set the repository to **Public** (or check your account plan's Pages options if you want a private repository).
5. Create the repository.
6. Click **Add file → Upload files**.
7. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder, plus the entire `assets` folder (including `pradeep-saini-portrait.png`). Upload the files themselves, not the ZIP archive.
8. Click **Commit changes**.
9. Open **Settings → Pages**.
10. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
11. Wait a few minutes and open `https://YOUR-USERNAME.github.io/`.

If you use a repository with a different name, the website URL will usually be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before publishing

- Confirm the internship dates, role, education and contact links.
- Check every tool listed and remove any tool you have not actually used.
- Verify course names and dates against original certificates.
- Add only certificate links/images that are safe and appropriate to share.
- Replace the illustrative Glitzora project artwork with genuine product photos when available.
- Add real screenshots only when you own them or have permission to publish them.
- Do not add confidential client details, private analytics, unapproved client names or unverified results.
- Consider whether you want your email publicly visible; if not, replace it with a contact form provider or a professional contact link.

## SEO / GEO notes

The page includes a descriptive title, meta description, Open Graph metadata, semantic headings, descriptive page copy, a Person JSON-LD block, accessible navigation and responsive layouts. These practices can help crawlers and people understand the site but do not guarantee search ranking or AI search visibility.

When publishing, use accurate, specific project descriptions and original evidence. Avoid keyword stuffing and do not claim results that cannot be verified.

## Customization

- Change colours near the top of `style.css` in the `:root` variables.
- Edit page text in `index.html`.
- Update LinkedIn and email links in `index.html`.
- Keep `index.html`, `style.css` and `script.js` in the same repository folder.
