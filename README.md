# Pradeep Saini — Digital Marketing Portfolio

A responsive, dark creative personal portfolio built with plain HTML, CSS and JavaScript. Designed for GitHub Pages.

## Files
- `index.html` — page content, SEO metadata and Person structured data
- `style.css` — responsive dark theme and layout
- `script.js` — mobile navigation and current year
- `assets/favicon.svg` — portfolio icon

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `pradeep-saini-portfolio` (or another name you prefer).
2. Upload all files and the `assets` folder from this project. Keep `index.html` in the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the deployment and open the URL shown in Settings → Pages.

If the repository is named `YOUR-USERNAME.github.io`, the website URL is usually `https://YOUR-USERNAME.github.io/`. Otherwise, it is usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before publishing
- Review the course names and dates against original certificates.
- Add real certificate images or credential URLs only after checking them.
- Add your own approved project screenshots/product photos to `assets/` and update the HTML if desired.
- Confirm that the listed tools accurately reflect your experience.
- No client names, confidential internship figures, or unverified campaign/business results are included.
- Replace the `og:url` metadata only if you add it later and know the final URL.
